# 6hp Wavefolder
![](https://github.com/Fihdi/MWMWM/blob/main/MWMWM.png?raw=true)

MWMWM is a 7 to 1 Wavefolder based on [Daveys Deadband](https://github.com/DaveyGraham/Daveys_Deadband) and Buchlas wavefolding method. At the maximum amount of wavefolding, a single wave cycle gets converted into seven cycles on the output.

The **FOLD** and the **CV** knob settings control the amount of wavefolding. 

**OFFSET** is the second input and is summed to the **IN** signal. Like the **OFFSET** knob, it can be used to offset the **IN** signal.

Fully analog design allows for audio rate modulation. Every input and output is DC biased and thus the module can be used with CV signals as well.
